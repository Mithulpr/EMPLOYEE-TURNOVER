## 1. Papers (`papers/`)
- **`Employee_Turnover_Two_Stage_Selective_IEEE_Final.docx`**: Final IEEE manuscript draft detailing the Two-Stage Selective Classification architecture, empirical holdout evaluations, and comparative baselines.
- **`IEEE_Paper_Two_Stage_Selective_Classification.docx`**: Earlier working draft of the selective classification methodology.

## 2. Reports (`reports/`)
A collection of 24 comprehensive markdown R&D reports documenting the development progression from early baseline experiments (v2–v8), forensics and error correction (v9), recall optimization (v10), AUC rank separation (v11), through feature representation and fusion (v12).

## 3. References (`references/`)
- **`1-s2.0-S2199853125000927-main.pdf`**: Primary published literature baseline:
  - *Authors*: Talebi et al. (2025)
  - *Title*: An empirical framework for employee turnover prediction using machine learning and genetic algorithms
  - *Journal*: Journal of Open Innovation: Technology, Market, and Complexity (JOItmC), Vol. 11, Iss. 1, 100557
  - *DOI*: 10.1016/j.joitmc.2025.100557
- **`outputs_base_paper_2969_extracted_text.txt`**: Plaintext extraction and tabular data parsing from the Talebi et al. publication.
